Fresh Groceries, Fruits & Hotel Food Delivery — Jetpack Compose

ℹ️
Native Android Application Note:
Sndmart is a 100% native Android app written in Kotlin + Jetpack Compose with Supabase backend and Google Play Location services. Native Android code runs on Android OS (devices or Android emulators), not as a web browser client. The preview below is a high-fidelity visual rendering of the actual Compose UI generated via Roborazzi.

Home Screen (Jetpack Compose)

City delivery bar, 15-min banner, category pills, & product cards

Architecture & Highlights

  • 📍
    GPS & City Detection
    Automatic high-accuracy location detector matching user coordinates to supported delivery cities via Supabase RPC.
  • ⚡
    Dual Mode Delivery
    Browse 15-minute quick grocery, fresh vegetables, fruits or order from local hotel restaurants with single-hotel cart validation.
  • 🛒
    Live Pricing & Cart
    Fresh price verification, quantity stepper controls, multi-item checkout, and delivery address picker.
  • 📱
    How to run on device / emulator:
    Export the repository to Android Studio or download the APK to install directly on an Android device (Android 7.0+ / API 24-36).
